| R1 | 2026-10-05 | Recorder is a standalone repo and Docker stack — summary of NOVA **D91** (full text there). (1) Own repo, rulebook, board (`REC-###`), decisions (`R#`) and guides; shares no code or Docker objects with NOVA; a change spanning both repos is one task on each board, linked by *Depends on*. (2) Compose project `nova-rec`: `rec-postgres` (TimescaleDB, `127.0.0.1:5433`, volume `rec-db-data`), `rec-migrate`, `rec-recorder`, `rec-api` (`127.0.0.1:8100`), image `nova-rec:dev`; tests use `rec-test-db` only. (6) Switch-over (NOVA-226): both recorders side by side for ≥ 2 trading days, then NOVA's recorder is removed and this repo's primary rule (never touch `nova-rec` containers on weekdays 08:55–15:45 IST) replaces NOVA D76. | NOVA work was blocked all day by live recording (shared Postgres, one image, no restarts). Kite has no tick history, so recording is the one process that must be isolated. |
| R2 | 2026-10-06 | **Manual delete only** (NOVA D91 (5) amended; Owner choices 2026-10-06). No automatic delete: Recorder keeps every day until the Owner presses **Delete** on Relay's Recorder card.
